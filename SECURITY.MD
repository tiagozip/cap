# security policy

please use [GitHub's security advisories](https://github.com/KurisuRakko/priestess-verification/security/advisories/new) to report any security issues.

if you find bots in the wild bypassing Cap Instrumentation's headless browser checks, please open a security advisory too so i can take a look.

if the issue also affects upstream Cap, please report it to them as well by following their [security policy](https://github.com/tiagozip/cap/security/policy).

## ai usage

security advisories found from ai scans are not currently allowed due to large amounts of low-quality issues.

for "CAPTCHA bypasses", a working fix is strictly required.
