# Conformité

Cap est conçu pour la confidentialité et l'auto-hébergement, ce qui rend la plupart des questions réglementaires simples à trancher : **les données de vos utilisateurs ne quittent jamais votre infrastructure.** Aucun cookie ni pistage pour les utilisateurs finaux, aucun appel tiers dans le flux de vérification, et la preuve de travail s'exécute entièrement dans le navigateur du visiteur.
