# แก้ปัญหา

การยืนยันนี้ล้มเหลวได้จากหลายสาเหตุ ไม่ใช่เพราะกิจกรรมของบอทเพียงอย่างเดียว ถ้าคุณยืนยันไม่ผ่าน ลองทำตามขั้นตอนต่อไปนี้

## 1. ลองใช้โหมดไม่ระบุตัวตนหรือโหมดส่วนตัว

เปิดโหมดไม่ระบุตัวตนหรือโหมดส่วนตัวของเบราว์เซอร์ เพื่อตัดปัญหาที่เกิดจากส่วนขยายหรือข้อมูลที่แคชไว้

- **Chrome / Edge:** กด `Ctrl+Shift+N` (Windows) หรือ `Cmd+Shift+N` (Mac)
- **Firefox:** กด `Ctrl+Shift+P` (Windows) หรือ `Cmd+Shift+P` (Mac)
- **Safari:** ไปที่ **File → New Private Window**

## 2. ปิดส่วนขยายของเบราว์เซอร์

ส่วนขยายบางตัวอาจรบกวนขั้นตอนการยืนยัน ลองปิดชั่วคราว:

1. เปิดหน้าตั้งค่าส่วนขยายหรือ add-on ของเบราว์เซอร์
2. ปิดส่วนขยาย**ทั้งหมด**ชั่วคราว
3. โหลดหน้าใหม่แล้วลองอีกครั้ง

ถ้าวิธีนี้แก้ปัญหาได้ ให้เปิดส่วนขยายกลับทีละตัวเพื่อหาตัวที่เป็นสาเหตุ

## 3. ลองเบราว์เซอร์หรืออุปกรณ์อื่น

ปัญหาอาจเกิดเฉพาะกับเบราว์เซอร์ที่คุณใช้อยู่ ลองเปลี่ยนไปใช้เบราว์เซอร์หรืออุปกรณ์อื่นเพื่อทดสอบ

- ลอง **Chrome**, **Firefox**, **Edge** หรือ **Safari**
- หมายเหตุ: **ไม่รองรับ Internet Explorer** ให้ใช้เบราว์เซอร์รุ่นใหม่แทน
- ถ้าเป็นไปได้ ลองบนอุปกรณ์อื่นไปเลย (เช่น โทรศัพท์ของคุณ)

## 4. อัปเดตเบราว์เซอร์

เบราว์เซอร์ที่เก่าเกินไปอาจทำให้การยืนยันล้มเหลว

1. เปิดเมนูของเบราว์เซอร์
2. ไปที่ **Help → About** (หรือเมนูที่ใกล้เคียง)
3. ติดตั้งอัปเดตที่มี แล้วรีสตาร์ตเบราว์เซอร์

## 5. เปลี่ยนไปใช้เครือข่ายอื่น

เครือข่ายที่คุณใช้อยู่อาจมีข้อจำกัดที่รบกวนการยืนยัน

- เชื่อมต่อ **Wi-Fi เครือข่ายอื่น**
- ลองใช้ **ฮอตสปอต** จากโทรศัพท์ของคุณ
- ถ้าคุณอยู่บนเครือข่ายของบริษัทหรือสถานศึกษา เครือข่ายเหล่านั้นมักกรองข้อมูลอย่างเข้มงวดจนอาจบล็อกการยืนยันได้

## 6. ปิดเซสชันเบราว์เซอร์อัตโนมัติทั้งหมด

ถ้าคุณใช้เบราว์เซอร์ที่ควบคุมด้วยซอฟต์แวร์อัตโนมัติ (เช่น Selenium, Puppeteer หรือ Playwright) การยืนยันจะถูกบล็อก

1. **ปิด** เซสชันเบราว์เซอร์อัตโนมัตินั้นให้สนิท
2. เปิดหน้านี้ใน **เบราว์เซอร์ปกติที่คุณควบคุมเอง**
3. ทำการยืนยันให้เสร็จที่นั่น

เบราว์เซอร์ของ AI agent ก็ถูกบล็อกเช่นกัน ขอให้แน่ใจว่าคุณใช้เบราว์เซอร์มาตรฐาน
