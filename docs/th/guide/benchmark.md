# การวัดประสิทธิภาพ

หน้านี้รัน proof of work แบบ HashWX ในเบราว์เซอร์ของคุณกับเซิร์ฟเวอร์จำลอง เพื่อให้คุณเห็นว่าการแก้หนึ่งครั้งใช้เวลานานเท่าไรบนอุปกรณ์ของคุณ ค่าเริ่มต้นตรงกับ site key ใหม่ใน capd ผลการวัดบนเบราว์เซอร์เดสก์ท็อปและโทรศัพท์ดูได้ที่ [HashWX](./hashwx.md#cost)
