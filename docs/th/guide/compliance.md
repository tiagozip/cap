# การปฏิบัติตามข้อกำหนด

Cap ออกแบบมาโดยให้ความสำคัญกับความเป็นส่วนตัวและการโฮสต์เอง ซึ่งทำให้คำถามด้านกฎระเบียบส่วนใหญ่ตอบได้ง่าย: **ข้อมูลผู้ใช้ของคุณไม่เคยออกจากโครงสร้างพื้นฐานของคุณ** ไม่มีคุกกี้หรือการติดตามสำหรับผู้ใช้ปลายทาง ไม่มีการเรียกบริการภายนอกในขั้นตอนการยืนยัน และ proof-of-work ทำงานทั้งหมดอยู่ในเบราว์เซอร์ของผู้เข้าชม
