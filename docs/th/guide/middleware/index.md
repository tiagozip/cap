# เกี่ยวกับ checkpoint

Checkpoint ของ Cap (เดิมเรียกว่า middleware) ช่วยให้คุณจำลองหน้าคั่นตรวจสอบเบราว์เซอร์แบบของ Cloudflare ได้ ซึ่งช่วยกันไม่ให้บอท, LLM และการใช้งานในทางที่ผิดแบบอัตโนมัติเข้าถึงเว็บไซต์ของคุณตั้งแต่แรก

มันตั้งค่าและใช้งานง่ายมาก คุณเพียงเพิ่มโค้ดไม่กี่บรรทัดในเซิร์ฟเวอร์ ต่างจากการต้องย้ายทั้งเว็บไซต์ไปอยู่บน Cloudflare ทั้งนี้ต้องบอกว่านี่เป็นวิธีที่ค่อนข้างรุนแรง เพราะมัน_จะ_กระทบบอทที่ดีอย่างครอว์เลอร์ของเสิร์ชเอนจินด้วย
