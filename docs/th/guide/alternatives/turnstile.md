# Cap กับ Cloudflare Turnstile

Turnstile คือตัวแทน CAPTCHA แบบฟรีของ Cloudflare ซึ่งเน้นการรัน challenge แบบล่องหนที่พึ่งพาสัญญาณจากเครือข่ายของ Cloudflare และการเก็บลายนิ้วมือเบราว์เซอร์เป็นหลัก

## สรุปสั้น ๆ

Turnstile ดีจริงถ้าคุณใช้ Cloudflare อยู่แล้วและยอมรับว่าคำตัดสินเป็นของพวกเขา ส่วน Cap เหมาะกว่าเมื่อคุณต้องการโฮสต์เอง ต้องการความยากที่กำหนดได้แน่นอน ไม่อยากพึ่งบุคคลที่สาม และอยากมีสิทธิ์ตัดสินใจแทนผู้ใช้ของคุณเอง

## Turnstile เหมาะเมื่อไร

- คุณส่งทราฟฟิกผ่าน Cloudflare อยู่แล้ว และอยากอยู่ในระบบนิเวศเดียว
- คุณไม่อยากโฮสต์อะไรเลย เพราะ Turnstile จัดการให้ทั้งหมด
- คุณยอมรับการตัดสินด้วยอัลกอริทึมของ Cloudflare กับผู้เข้าชมที่ถูกมองว่า "น่าสงสัย" โดยไม่มีทางแก้

## Cap เป็นตัวเลือกที่ดีกว่าเมื่อไร

- **โฮสต์เองได้** Cap รันบนเซิร์ฟเวอร์ของคุณ ส่วน Turnstile บังคับให้ทุก challenge ต้องวิ่งผ่าน Cloudflare
- **นโยบายเป็นของคุณ** กับ Turnstile ถ้าอัลกอริทึมของ Cloudflare ตัดสินว่าผู้ใช้ดูน่าสงสัย (พบบ่อยกับผู้ใช้ Brave, Librewolf, Tor หรือ VPN) คุณแก้อะไรไม่ได้ แต่ Cap วางปุ่มปรับความยากไว้ในมือคุณ
- **อัตราพลาดต่ำกว่าสำหรับผู้ใช้ที่ใส่ใจความเป็นส่วนตัว** มีรายงานอย่างกว้างขวางว่า Turnstile จำแนกเบราว์เซอร์ที่ตั้งค่าเข้มผิดพลาด ขณะที่ proof-of-work ของ Cap ไม่สนใจลายนิ้วมือเลย
- **โอเพนซอร์ส** Apache 2.0 เทียบกับไคลเอนต์และเซิร์ฟเวอร์แบบปิดซอร์สของ Turnstile
- **ไม่มีเทเลเมทรี** Cap ไม่ส่งข้อมูลกลับและไม่ตั้งคุกกี้ ส่วนไคลเอนต์ของ Turnstile ติดต่อกับ `challenges.cloudflare.com` ทุกครั้งที่โหลดหน้า
- **ปรับแต่งได้** Cap เปิดตัวแปร CSS สำหรับสี ขนาด และรูปทรง ขณะที่ iframe ของ Turnstile แทบปรับอะไรไม่ได้

## สิ่งที่คล้ายกัน

ทั้งคู่ส่งไคลเอนต์ขนาดเล็ก (ราว 20-110 KB) ทั้งคู่มีโหมด "ล่องหน" (Cap เรียกว่า[โหมดลอย](../floating.md) หรือ[โหมด programmatic](../programmatic.md)) และทั้งคู่ซ้อนการตรวจเชิงพฤติกรรมทับ challenge หลัก โดย Cap เรียกมันว่า [challenge แบบ instrumentation](../instrumentation.md) ส่วน Turnstile เรียกว่า "managed challenge"

## การย้ายระบบ

รูปแบบ API `/siteverify` ของ Cap เข้ากันได้กับ `siteverify` ของ Cloudflare การตรวจสอบฝั่งเซิร์ฟเวอร์จึงแทบเป็นเพียงการเปลี่ยน URL กับ secret ส่วนฝั่งไคลเอนต์คือเปลี่ยน `<div class="cf-turnstile">` เป็น `<cap-widget>` แล้วชี้ไปยังอินสแตนซ์ Cap ของคุณ ดูโค้ดเต็มได้ที่[คู่มือเริ่มต้นใช้งาน](../index.md)
