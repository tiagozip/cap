# Cap กับ Altcha

Altcha คือโปรเจกต์ที่ใกล้เคียงกับ Cap ในแง่แนวคิดมากที่สุด: โอเพนซอร์ส ใช้ proof-of-work ไม่เก็บลายนิ้วมือ และไม่พึ่งบุคคลที่สาม ทั้งคู่เป็นตัวเลือกที่ดี ความต่างอยู่ที่ฟีเจอร์และรูปแบบการใช้งานจริง

Altcha ยังมีผลิตภัณฑ์เชิงพาณิชย์ชื่อ **Altcha Sentinel** ซึ่งเพิ่มการตรวจจับภัยคุกคามด้วย ML ทับบนวิดเจ็ตโอเพนซอร์ส การเปรียบเทียบด้านล่างส่วนใหญ่เป็นระหว่าง Cap กับวิดเจ็ต Altcha แบบโอเพนซอร์ส ถ้าคุณกำลังพิจารณา Sentinel นั่นคือการเทียบ SaaS แบบเสียเงินกับโปรเจกต์โอเพนซอร์สที่โฮสต์เอง ซึ่งเป็นการตัดสินใจคนละเรื่อง

## สรุปสั้น ๆ

ถ้าคุณอยากได้ CAPTCHA แบบ PoW ที่เล็กและใช้เหมือนไลบรารี วางลงในโปรเจกต์ Node แล้วลืมมันไปได้เลย Altcha แบบโอเพนซอร์สนั้นดีมาก แต่ถ้าคุณอยากได้บริการที่โฮสต์เองแบบพร้อมใช้ มีแดชบอร์ด รองรับ site key หลายชุด มี challenge แบบ instrumentation ซ้อนบน PoW และมี UI ที่แสดงความคืบหน้าของการแก้ (โดยไม่ต้องจ่ายค่า Sentinel) Cap เหมาะกว่า

## Altcha เหมาะเมื่อไร

- คุณอยากได้การผนวกแบบจิ๋ว ๆ ที่เป็นแค่ไลบรารี ไม่ต้องรันบริการแยก
- คุณไม่ต้องการชั้นตรวจสอบที่สองนอกเหนือจาก proof-of-work หรือยินดีจ่ายค่า Sentinel เพื่อให้ได้การตรวจจับด้วย ML
- คุณผนวกกับ Altcha ไว้แล้ว และต้นทุนการย้ายมากกว่าความต่างที่ระบุด้านล่าง

## Cap เป็นตัวเลือกที่ดีกว่าเมื่อไร

- **สองชั้นการตรวจสอบที่เป็นอิสระต่อกัน แบบฟรี ๆ** Cap รัน proof-of-work *และ* [challenge แบบ instrumentation](../instrumentation.md) ที่สร้างด้วย JavaScript แบบไดนามิกไปพร้อมกัน โดยรวมมาให้ทั้งคู่ การเจาะชั้นหนึ่งได้ไม่ได้แปลว่าเจาะอีกชั้นได้ ส่วน Altcha โอเพนซอร์สมีแค่ PoW ชั้นที่สอง (ที่ใช้ ML) ต้องจ่ายค่า Sentinel
- **เซิร์ฟเวอร์ standalone พร้อมแดชบอร์ด แบบฟรี ๆ** Cap ส่งมอบการดีพลอยแบบคอนเทนเนอร์ Docker ตัวเดียว พร้อมแดชบอร์ดบนเว็บ การจัดการ site key หลายชุด ระบบวิเคราะห์ข้อมูล และ endpoint siteverify ที่เข้ากันได้กับ reCAPTCHA ขณะที่ฝั่งโอเพนซอร์สของ Altcha ปล่อยให้คุณต่อเองทั้งหมด ประสบการณ์แบบครบจบมีเฉพาะใน Sentinel
- **วิดเจ็ตเล็กกว่า** Cap ราว 20 KB ส่วน Altcha ราว 34 KB เมื่อบีบอัดด้วย gzip
- **แสดงความคืบหน้า** วิดเจ็ตของ Cap รายงานความคืบหน้าของการแก้ให้ผู้ใช้เห็นเป็นเปอร์เซ็นต์ ซึ่งเป็นการตอบสนองที่มีความหมายระหว่างช่วงรอสั้น ๆ
- **โหมดลอยและโหมด programmatic** Cap ซ่อนตัวได้ทั้งหมด หรือลอยอยู่เหนือปุ่มจนกว่าจะส่งฟอร์ม ส่วนโหมดการแสดงผลของ Altcha เรียบง่ายกว่า
- **ปรับหน้าตาได้** Cap เปิดตัวแปร CSS สำหรับสี ขนาด ตำแหน่ง และไอคอน ขณะที่ Altcha ปรับแต่งได้จำกัดกว่า

## สิ่งที่คล้ายกัน

- ทั้งคู่โอเพนซอร์ส (Cap ใช้ Apache 2.0 ส่วนวิดเจ็ตของ Altcha ใช้ MIT) และไม่มีเทเลเมทรี
- ทั้งคู่รัน proof-of-work ฝั่งไคลเอนต์เพื่อทำให้การใช้งานในทางที่ผิดมีต้นทุนสูง
- ทั้งคู่ทำงานได้โดยไม่ต้องวิ่งไปหาเครือข่ายของบุคคลที่สามเลยเมื่อโฮสต์เอง
- ทั้งคู่ออกแบบมาให้เป็นมิตรกับ GDPR/CCPA ตั้งแต่ต้น
