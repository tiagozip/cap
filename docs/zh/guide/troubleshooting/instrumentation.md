# 故障排查

这项验证可能因多种原因失败，并不一定是机器人行为所致。如果你无法完成验证，请按以下步骤排查。

## 1. 尝试无痕或隐私模式

打开浏览器的无痕或隐私模式，以排除扩展或缓存数据导致的问题。

- **Chrome / Edge：**按 `Ctrl+Shift+N`（Windows）或 `Cmd+Shift+N`（Mac）
- **Firefox：**按 `Ctrl+Shift+P`（Windows）或 `Cmd+Shift+P`（Mac）
- **Safari：**打开 **File → New Private Window**（文件 → 新建隐私浏览窗口）

## 2. 禁用浏览器扩展

某些扩展可能会干扰验证流程。请尝试临时禁用它们：

1. 打开浏览器的扩展或附加组件设置
2. 临时禁用**所有**扩展
3. 刷新页面并重试

如果问题因此解决，请逐个重新启用扩展，找出罪魁祸首。

## 3. 换一个浏览器或设备

问题可能只出现在你当前的浏览器上。请换用其他浏览器或设备测试。

- 尝试 **Chrome**、**Firefox**、**Edge** 或 **Safari**
- 注意：**不支持 Internet Explorer**，请改用现代浏览器
- 如有条件，换一台完全不同的设备试试（例如你的手机）

## 4. 更新浏览器

过旧的浏览器可能导致验证失败。

1. 打开浏览器菜单
2. 进入**帮助 → 关于**（或类似入口）
3. 安装可用更新并重启浏览器

## 5. 切换到其他网络

你当前的网络可能存在干扰验证的限制。

- 连接到**其他 Wi-Fi 网络**
- 尝试使用手机开启的**移动热点**
- 如果你在公司或学校网络中，这类网络往往有严格的过滤策略，可能会拦截验证

## 6. 关闭所有自动化浏览器会话

如果你使用的是由自动化软件（如 Selenium、Puppeteer 或 Playwright）控制的浏览器，验证将被拦截。

1. **彻底关闭**自动化浏览器会话
2. 在**常规的、手动操作的浏览器**中打开页面
3. 在那里完成验证

AI 智能体浏览器同样会被拦截——请确保使用标准浏览器。

---

如果以上方法都试过仍无法通过，请考虑联系站点所有者寻求进一步帮助。你也可以[提交 issue](https://github.com/tiagozip/cap/issues)。
