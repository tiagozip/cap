## Benchmark-Ergebnisse

Diese Messungen nutzen einen Platzhalter-Server, die Geschwindigkeiten können je nach Setup und Netzwerklatenz abweichen.

Für diese Benchmarks wurde eine Challenge-Schwierigkeit von 4 mit 50 Challenges auf WASM 0.0.7 verwendet.

| Klasse     | Gerät              | Zeit  |
| ---------- | ------------------ | ----- |
| Einsteiger | Samsung Galaxy A34 | 795ms |
| Einsteiger | iPhone SE (2020)   | 798ms |
| Mittel     | Google Pixel 7     | 423ms |
| High-End   | Google Pixel 9     | 414ms |
| High-End   | M3 Macbook         | 212ms |
